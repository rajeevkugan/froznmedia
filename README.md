# FROZN Media site

Static site (no build step). Edit `config.js` to change Instagram posts, YouTube films, trusted names and services.

- Preview: `python3 -m http.server 5180` then open http://127.0.0.1:5180
- Add Rajeev's photo as `assets/rajeev.jpg` (falls back to initials).
- Add YouTube films: put 11-char video IDs in `config.js` → `youtube`.
